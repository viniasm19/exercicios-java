# ☕ Exercícios Java - Alura

## 📋 Sobre o projeto
Repositório com exercícios e desafios complementares propostos durante o curso de Java da Alura. Cada exercício é uma classe separada, focada nos primeiros conceitos da linguagem — estrutura básica de uma classe, o método `main` e o comando `System.out.println`.

## 🎮 Como usar
Cada desafio é uma classe Java independente, sem ordem obrigatória de execução. Basta abrir o arquivo `.java` correspondente e rodar para ver o resultado impresso no console.

## ✨ Funcionalidades
- Impressão de mensagens personalizadas no console
- Cálculo e exibição de operações aritméticas (soma, subtração, média)
- Conversão de tipos primitivos (casting de `double` para `int`)
- Conversão de temperatura de Celsius para Fahrenheit
- Registro de anotações de estudo em forma de código

## 🛠️ Tecnologias utilizadas
- Java
- IntelliJ IDEA

## 🚀 Como executar
1. Clone o repositório:
```
git clone https://github.com/viniasm19/exercicios-java.git
```
2. Abra o projeto no IntelliJ (ou outra IDE de sua preferência)
3. Execute a classe desejada (botão direito → Run) ou compile e rode via terminal:
```
javac Perfil.java
java Perfil
```

## 📚 Aprendizados
- Estrutura básica de uma classe Java (`public class`)
- O método `main` como ponto de entrada do programa
- Uso do `System.out.println()` para exibir texto e resultados de operações no console
- Diferença entre imprimir texto (com aspas) e imprimir o resultado de uma expressão numérica (sem aspas)
- Operações aritméticas básicas (soma, subtração e média) diretamente no `println`
- Casting (conversão explícita de tipo) de `double` para `int`
- Uso do `String.format()` para montar strings com valores numéricos interpolados
